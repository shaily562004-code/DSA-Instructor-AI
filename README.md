# ⚡ DSA Instructor AI

An AI-powered learning platform designed to help students learn **Data Structures and Algorithms (DSA)** interactively.

The application uses the **Google Gemini API** to provide explanations, examples, and guidance for DSA concepts in simple English or Hinglish.

## 🚀 Features

- 🤖 AI-powered DSA Tutor
- 📚 Practice Problems
- 💡 Hints and Solutions
- 💬 Conversation support
- 🔐 User Authentication (Sign Up, Login and Logout)
- 📝 Code formatting with syntax highlighting
- 📋 Copy button for code examples
- 🌐 Simple and interactive user interface

## 🛠️ Technologies Used

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

```bash
cd DSA-Instructor-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a `.env` file

Add your API key:

```env
GEMINI_API_KEY=your_api_key_here
SESSION_SECRET=your_session_secret_here
```

### 5. Start the server

```bash
node server.js
```

### 6. Open the application

Open:

```text
http://localhost:3000
```
